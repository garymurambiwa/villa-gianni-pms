# COREPMS User Manual

## 1. Introduction
COREPMS is a comprehensive Property Management System designed for hotels and resorts. This manual covers the basic operations of the system.

## 2. Getting Started
### 2.1 Login
- Launch the application.
- Enter your username and password.
- **Default Admin**: The system creates a default admin account during installation if one doesn't exist. Check installation logs or ask your administrator.
- **Two-Factor Authentication**: If enabled, enter the verification code sent to your email.

### 2.2 Dashboard
The main dashboard provides an overview of:
- Today's Arrivals and Departures
- Room Occupancy Status
- Recent Activity Logs
- Key Performance Indicators (RevPAR, ADR)

## 3. Room Management
### 3.1 Room Status
- **Vacant Clean (VC)**: Room is ready for check-in.
- **Occupied (OCC)**: Room is currently occupied.
- **Dirty (VD/OD)**: Room needs housekeeping.
- **Out of Order (OOO)**: Room is unavailable for maintenance.

### 3.2 Adding Rooms
- Navigate to **Rooms** module.
- Click **Add Room**.
- Enter Room Number, Type, Rate, and Floor.
- Click **Save**.

## 4. Front Office
### 4.1 Check-In
- Go to **Front Office** or **Reservations**.
- Select a reservation or create a new walk-in.
- Verify guest details and assign a room.
- Click **Check In**.

### 4.2 Check-Out
- Select the guest/room.
- Review the folio (charges and payments).
- Process payment if balance is pending.
- Click **Check Out**.

## 5. Point of Sale (POS)
- Navigate to **POS**.
- Select Outlet (Restaurant/Bar).
- **Take Order**: Select items from the menu.
- **Billing**:
  - **Charge to Room**: Select guest room to transfer charges to folio.
  - **Cash/Card**: Process direct payment.

## 6. Reports
- **Night Audit**: Run the daily closing process to post room charges and generate daily reports.
- **Occupancy Report**: View historical and forecasted occupancy.
- **Financial Report**: View revenue breakdown.

## 7. Settings
- **Users**: Manage staff accounts and roles.
- **Rates**: Configure room rates and seasons.
- **System**: Configure tax rates, receipt templates, and database settings.

## 8. Support
For technical support, contact your system administrator or refer to the `INSTALLATION.md` guide for troubleshooting.
