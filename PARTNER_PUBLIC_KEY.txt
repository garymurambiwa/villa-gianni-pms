## How to Add to Server (Admin Only)

Run this command on the Hetzner server:

```bash
# Create .ssh directory if it doesn't exist
mkdir -p ~/.ssh

# Add the public key to authorized_keys
echo "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAINwGdmi518MtykFBttra2MAYrzfX2gVU8wn6Kszxo/AW partner@hetzner-vg" >> ~/.ssh/authorized_keys

# Fix permissions
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys

# Verify (should show the key)
cat ~/.ssh/authorized_keys
```
